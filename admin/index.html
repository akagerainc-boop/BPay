How USSD templates work

Each template is the exact code BPay dials. Put a placeholder where the user's own input belongs — the app substitutes it before dialling.

  • {recipient} phone number the user entered
  • {amount} amount in RWF (digits only)
  • {code} merchant / till code
  • {account} meter, account or reference number

Example — *182*1*1*{recipient}*{amount}# sending 5,000 to 0788123456 dials *182*1*1*0788123456*5000#.

Leave a template with no placeholders (like *182#) to simply open the carrier menu, and untick Completes payment so the app tells the user to finish there.

Once a network crosses this threshold, BPay asks the user to pay this fee via a real Request-to-Pay (MTN MoMo / Airtel Money) before continuing — see Provider API keys below for the credentials that makes it an actual charge, not just a notice. Their main payment still runs through whichever USSD code is set up in USSD codes / Services above, unchanged by this.

Provider API keys

Real credentials for the MTN MoMo / Airtel Money Collections API — the "Request to Pay" that actually charges the fee above from the user's own wallet into this company's account. This is separate from USSD dialling entirely: it's a direct server-to-server call, which is why it needs real credentials from MTN/Airtel's developer portal. Secrets are masked here and never sent to the app.
